# Fonts

The stylesheet editor ships two coding fonts, both under the SIL Open Font License 1.1 (license texts alongside each).

- [Maple Mono](https://font.subf.dev/) v7.9 by the Maple Mono Project Authors: upstream variable fonts, converted to WOFF2.
- [Iosevka](https://typeof.net/Iosevka/) v34.9.1 by Renzhi Li (Belleve Invis): upstream unhinted WOFF2, reduced to Latin, punctuation, arrows, math and box-drawing characters, with all OpenType features (ligatures included) kept.

`tools/build-fonts.sh` rebuilds this folder from the upstream releases.
